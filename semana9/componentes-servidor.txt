Sistema operativo:
Es el software principal que administra los recursos del computador o servidor. Permite ejecutar aplicaciones y gestionar procesos.

Node.js:
Es un entorno de ejecución que permite ejecutar código JavaScript fuera del navegador. Se utiliza para crear aplicaciones y servidores.

Aplicación server.js:
Es el archivo que contiene el código del servidor. Define las rutas y la lógica que responderá a las solicitudes de los usuarios.

Puerto:
Es un punto de comunicación que permite que las aplicaciones reciban conexiones. En esta práctica se utiliza el puerto 3000.

Logs:
Son registros de eventos y actividades del sistema o aplicación. Ayudan a monitorear el funcionamiento y detectar errores.
